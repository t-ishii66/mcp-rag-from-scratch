# 検索対象のドキュメント

このフォルダの `.txt` が RAG の検索対象になる。

内容はすべて**架空のカフェ「The Wandering Kettle」**の資料であり、
実在の店舗・人物とは一切関係ない。

架空にしているのには理由がある。LLM が学習済みの知識で答えられてしまうと、
検索が効いているのかどうかが分からなくなる。実在しない店の営業時間は、
どんなに賢い LLM も検索なしには答えられない。

| ファイル | 内容 |
|---------|------|
| `menu_drinks.txt` | ドリンクのメニューと価格 |
| `menu_food.txt` | フードのメニューと価格 |
| `hours_access.txt` | 営業時間、場所、行き方、駐輪場 |
| `faq.txt` | よくある質問（Wi-Fi、電源、予約、ペット、支払い） |
| `allergens.txt` | アレルギーと食事制限（乳・小麦・ナッツ・ヴィーガン） |
| `staff_handbook.txt` | スタッフ向けの手引き（開店・閉店作業、シフト） |
| `story.txt` | 店の成り立ち、オーナー、焙煎の話 |

## 差し替えるには

`.txt` を好きな内容に置き換えれば、そのまま別用途の検索ツールになる。
ファイル形式は素のテキストで、**空行で区切られたかたまり**を1つの話題として扱う。
